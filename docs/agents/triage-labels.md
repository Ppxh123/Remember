# 分诊标签

按此表将技能使用的英文角色映射到 GitHub 中文标签。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待分诊` | 等待维护者评估 |
| `needs-info` | `待补充信息` | 等待提报者补充信息 |
| `ready-for-agent` | `可由智能体处理` | 任务描述已齐备，智能体可独立执行 |
| `ready-for-human` | `需人工处理` | 需要人工执行 |
| `wontfix` | `不予处理` | 维护者决定不处理 |

调整 GitHub 标签命名时，同步更新此表的第二列。
