# 领域文档

Remember 采用单上下文布局。仓库根目录的 `CONTEXT.md` 保存领域术语，`docs/adr/` 保存架构决策记录（ADR）。

## 开始探索前

- `CONTEXT.md` 存在时，先读取术语和定义。
- `docs/adr/` 存在时，读取与当前任务相关的 ADR。
- 缺少相应文档时，继续探索。通过 `domain-modeling` 确定新术语或架构决策后，再补充对应文档。

## 使用领域术语

为 Issue、重构方案、假设和测试命名时，沿用 `CONTEXT.md` 的定义。发现术语缺口时，记录给 `domain-modeling` 讨论。

## 提示架构决策冲突

方案与已有 ADR 冲突时，指出具体的 ADR，并说明为什么值得重新讨论该决策。
